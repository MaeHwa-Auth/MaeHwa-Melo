# MaeHwa Melo 사용자 가이드

## 음악 가져오기

앱 홈이나 라이브러리에서 가져오기 버튼을 누릅니다.

- **곡 파일 추가**: Windows 파일 선택창에서 한 개 또는 여러 개의 곡을 선택합니다.
- **폴더 추가**: 폴더 안의 지원되는 음악 파일을 하위 폴더까지 검색합니다. 폴더 위치를 기억하므로 다음 실행 때 다시 검색합니다.

지원 확장자는 MP3, FLAC, WAV, M4A, AAC, OGG, Opus, AIFF, APE, WavPack입니다. 파일 이름을 기본 곡 제목으로 사용하고, 태그가 있으면 곡/아티스트/앨범/트랙 번호/연도/장르와 embedded 커버를 읽습니다. 폴더 커버도 찾습니다. 음악 파일은 원래 위치에 남습니다.

추가한 파일이나 폴더를 이동·삭제하면 해당 곡을 재생하지 못할 수 있습니다. 설정에서 저장된 폴더의 **갱신**을 눌러 다시 검색하세요. 개별 파일은 저장된 경로를 앱 시작 시 다시 확인합니다.

## 라이브러리

- **전체 / 로컬 음악 / Spotify** 탭으로 소스를 바꿉니다.
- 라이브러리의 필터 입력은 곡 제목, 아티스트, 앨범을 찾습니다. Spotify 계정이 연결된 상태면 Spotify 카탈로그 결과도 함께 찾습니다.
- **앨범** 보기로 바꾸면 앨범 커버와 곡 수를 기준으로 정리됩니다. 앨범 카드를 누르면 그 앨범 순서대로 재생합니다.
- 하트 버튼으로 즐겨찾기에 추가합니다. 왼쪽의 즐겨찾기 메뉴에서 다시 모아 볼 수 있습니다.
- Spotify 탭에서 플레이리스트를 선택하면 해당 곡 목록을 불러옵니다.
- Spotify 곡 목록의 **정렬** 메뉴에서 기본 순서, 최신/오래된 추가순, 재생 시간 짧은/긴 순을 선택할 수 있습니다. 정렬은 Melo 화면과 해당 목록에서 시작하는 재생 대기열에 적용되며 Spotify 플레이리스트 원본 순서는 바꾸지 않습니다.
- Spotify 탭의 **좋아요 표시한 곡** 항목에서 Spotify에 저장한 좋아요 곡을 모아 보고 재생할 수 있습니다.
- Spotify 탭의 **새 플레이리스트**에서 공개 범위를 공개 또는 비공개로 선택해 만들 수 있습니다. 공개 플레이리스트는 Spotify 프로필에 표시됩니다.
- 상단 검색 결과 옆 `+`를 누르면 플레이리스트를 골라 곡을 추가합니다. Spotify 라이브러리에서 플레이리스트를 먼저 선택하면 그 목록에 바로 추가할 수 있습니다.
- 검색 결과의 `+` 메뉴에서 **새 플레이리스트 만들기**를 고르면 공개 범위를 선택해 곡을 담은 플레이리스트를 만들 수 있습니다.

## 재생 조작

- 곡 행 또는 앨범 카드를 눌러 재생을 시작합니다.
- 하단 플레이어에서 재생/일시정지, 이전/다음, 셔플, 반복, 재생 위치, 음량, 대기열을 조작합니다.
- 키보드 `Space`는 재생/일시정지, `←`와 `→`는 현재 곡의 재생 위치를 5초씩 이동합니다. 입력창에 포커스가 있으면 단축키가 동작하지 않습니다.
- 반복 모드는 끔 → 전체 반복 → 한 곡 반복 순서로 바뀝니다.

## 지금 재생 패널과 가사

- 하단 왼쪽의 앨범 커버를 누르면 오른쪽에 지금 재생 패널을 엽니다. 패널 커버나 닫기 버튼, 또는 하단 앨범 커버를 다시 누르면 슬라이드 애니메이션과 함께 닫힙니다.
- 패널 경계선을 드래그해 폭을 조절할 수 있습니다. 조절한 너비는 앱에 저장됩니다.
- 하단 오른쪽의 **가사** 버튼을 누르면 패널과 가사 카드를 엽니다. 버튼을 다시 누르면 가사 카드만 접습니다.
- 가사는 LRCLIB에서 곡 제목과 아티스트, 앨범 및 재생 시간으로 조회합니다. 등록된 가사가 없거나 네트워크가 끊기면 카드에 상태를 표시합니다.
- 싱크 가사에서 문장 또는 단어를 누르면 해당 시점으로 재생 위치가 이동합니다.
- 단어별 싱크가 제공되는 곡은 카드 오른쪽 위의 **단어 싱크 / 문장 싱크** 표시를 눌러 보기 방식을 바꿀 수 있습니다. 단어별 데이터가 없는 곡은 문장 단위 또는 일반 가사만 표시됩니다.
- 재생 중에는 현재 문장/단어를 강조합니다. 가사 카드 안을 직접 스크롤하면 자동 따라가기를 잠시 멈추며, 일정 시간 뒤 다시 현재 줄을 따라갑니다.
- 가사 버튼은 LRCLIB 요청을 시작합니다. LRCLIB에 등록된 데이터 범위에 따라 곡별로 싱크 수준이 다를 수 있습니다.

## Spotify 플레이리스트 관리

- Spotify 화면의 정렬 메뉴는 현재 화면과 그 목록에서 시작하는 재생 순서에만 적용하며 Spotify 플레이리스트 자체의 저장 순서를 변경하지 않습니다.
- **새 플레이리스트**에서 이름을 입력하고 공개 범위를 선택합니다. 비공개는 본인만 볼 수 있고, 공개는 Spotify 프로필에 표시됩니다.
- 검색 결과의 추가 버튼에서 현재 선택한 플레이리스트에 곡을 넣거나, 새 플레이리스트를 만들어 검색 곡을 담을 수 있습니다.
- Spotify의 **좋아요 표시한 곡**은 플레이리스트 목록에서 열고 재생합니다.

## Spotify 연결

1. MaeHwa Melo의 **설정** 또는 왼쪽 Spotify 연결 카드를 누릅니다.
2. 브라우저 또는 Spotify 앱에서 Spotify 계정으로 로그인하고 Melo의 접근 권한을 허용합니다.
3. 인증이 끝나면 MaeHwa Melo 창으로 자동 복귀합니다.

사용자는 Developer Dashboard에 앱을 등록하거나 Client ID를 입력하지 않습니다. Client ID와 `http://127.0.0.1:43821` loopback redirect 설정은 앱 개발자가 빌드 전에 준비합니다. 로그인은 데스크톱 앱에 적합한 PKCE 방식으로 처리하며 Client Secret은 사용하지 않습니다. 저장한 곡과 플레이리스트는 Spotify 계정 권한 및 API 접근 정책에 따라 표시됩니다. Web Playback은 Spotify Premium이 필요합니다. Spotify 개발 모드로 배포하면 앱 소유자의 Premium 조건과 사용자 허용 목록 및 계정 한도가 적용될 수 있습니다.

플레이리스트를 만들거나 곡을 추가하려면 Spotify가 `playlist-modify-private` 및 `playlist-modify-public` 권한을 요청합니다. 기존 연결에서 권한을 허용하지 않았다면 Spotify 재인증을 한 번 진행해야 합니다.

연결 해제는 설정에서 할 수 있습니다. 로그인 토큰은 앱의 로컬 WebView 저장소에 기록됩니다. MaeHwa Melo 계정이나 클라우드 동기화는 없습니다.

## 브라우저 미리보기 제한

`npm run dev`로 여는 브라우저 화면은 UI 및 기본 오디오 재생 확인용입니다.

- 파일/폴더 선택은 브라우저의 권한 선택창을 사용합니다.
- 선택 파일은 현재 탭에만 남으며 새로고침하면 다시 선택해야 합니다.
- 재생 가능한 오디오 형식은 사용 중인 브라우저 코덱에 달려 있습니다.
- Windows 폴더의 태그/커버 전체 검색과 Spotify 데스크톱 OAuth는 Tauri 앱에서 확인하세요.

## 자주 발생하는 문제

### 곡이 목록에 나타나지 않음

확장자가 지원되는지 확인하세요. 폴더에서 읽은 파일은 오디오 메타데이터 파서가 열 수 있어야 합니다. 폴더가 이동되었으면 설정에서 갱신합니다.

### 앨범 커버가 없음

embedded 커버를 우선 사용합니다. 태그에 이미지가 없다면 곡과 같은 폴더에서 `cover.*`, `folder.*`, `front.*` 또는 이름에 `cover`, `album`, `front`, `artwork`가 포함된 JPG/JPEG/PNG/WebP 이미지를 찾습니다.

### 앱이 시작되지 않거나 빈 창이 나옴

Windows WebView2 Runtime이 설치되어 있는지 확인하고 앱을 다시 엽니다. 개발 버전에서는 Tauri와 MSVC 도구체인도 설치되어 있어야 합니다.

### Spotify 로그인/재생 실패

인터넷 연결과 Spotify Premium 요건을 확인하세요. 개발 모드에서는 계정이 Spotify 앱의 허용 목록에 있어야 할 수 있습니다. 앱 설정이 포함되지 않은 개발 빌드에서는 Spotify 연결 버튼을 사용할 수 없으며 앱 관리자에게 설정된 빌드를 요청하세요.
